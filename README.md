# Team TaskFlow - ระบบจัดการงานทีม (Team Todo, Kanban, Calendar & Daily Summary)

ระบบ Todo List, Kanban Board, ปฏิทินไทม์ไลน์ และ **สรุปงานประจำวันของแต่ละคน (Daily Summary / Daily Agenda)** สำหรับทีม ผลิตคอนเทนต์/วิดีโอ ออกแบบให้เห็นภาพรวมงานของทุกคน และให้ทีมงานแต่ละคนจัดการงานของตนเองได้อย่างง่ายดาย พร้อมรองรับการมอบหมายผู้รับผิดชอบงานได้หลายคน (Multiple Assignees) และการเลือกประเภทรายละเอียดงานได้หลายตัวเลือกพร้อมกัน

## 🎬 ตัวเลือกลักษณะงาน (Multi-Select Task Options)

ระบบได้เปลี่ยนช่องรายละเอียดงานเดิม เป็น **ตัวเลือกประเภทงานแบบเลือกได้หลายตัวเลือกพร้อมกัน (Multi-Select Options)** ที่สอดคล้องกับสายงานผลิตวิดีโอและคอนเทนต์:

| ตัวเลือก | ไอคอน | สี Badge | คำอธิบายลักษณะงาน |
| :--- | :---: | :--- | :--- |
| **Roll A** | 🎬 | สีฟ้า | บันทึกภาพกล้องหลัก / วิดีโอบทสนทนาหลัก / เส้นเรื่องหลัก |
| **ins** | 📹 | สีม่วง | ถ่าย Footage เจาะ / แทรก Insert / B-Roll ประกอบคลิป |
| **ตัดต่อ** | ✂️ | สีเขียวอมฟ้า (Teal) | ตัดต่อวิดีโอ, Rough Cut, Fine Cut, ตัดต่อเสียง, เกรดสี |
| **Short** | 📱 | สีชมพู | คลิปสั้นแนวตั้ง (TikTok, Reels, YouTube Shorts) |
| **เขียนสคริปต์** | 📝 | สีเหลืองอำพัน | ร่างบทสคริปต์, Outline, Tie-in ลูกค้า, จัดลำดับรายการ |
| **กราฟฟิก** | 🎨 | สีเขียว | ออกแบบหน้าปก Thumbnail, Motion Graphic, Intro, CG |
| **ปล่อยงาน** | 🚀 | สีครามเข้ม | ตรวจ Final, Export, อัปโหลด และ Publish เผยแพร่คลิป |
| **แก้งาน** | 🛠️ | สีส้มอิฐ (Orange) | ปรับปรุงแก้ไขตามคอมเมนต์ลูกค้า/บรีฟ, แก้เสียง/ภาพ, Re-edit, Revision |

* **เลือกได้หลายตัวเลือก:** ใน 1 งานสามารถเลือกได้ทั้ง Roll A + ins หรือ ตัดต่อ + Short หรือตัวเลือกใดๆ ร่วมกันได้อย่างอิสระ
* **ปุ่มลัด:** มีปุ่ม "เลือกทั้งหมด" และ "ล้างค่า" ในหน้าต่างสร้าง/แก้ไขงาน
* **ช่องหมายเหตุเพิ่มเติม:** มีช่องกรอกลิงก์ส่งงาน หรือข้อความกำกับเพิ่มเติมด้านล่าง
* **การแสดงผล:** ตัวเลือกที่เลือกจะแสดงเป็น **Badge ป้ายกำกับสีสวยงาม** อย่างชัดเจนทั้งในกระดาน Kanban, ตารางงาน (Table) และสรุปงานประจำวัน (Daily Summary)

## 🏗️ โครงสร้างการจัดวางหน้าจอ (Layout Architecture)

ระบบได้จัดระเบียบหน้าจอแยกเป็นส่วนหลักอย่างชัดเจน โดยนำ **ปฏิทินไทม์ไลน์** และ **สรุปงานประจำวัน** แยกกล่องอิสระออกจากกันและยกขึ้นมาไว้ด้านบนสุด:

### 1. ส่วนบนสุด: ปฏิทินไทม์ไลน์ และ สรุปงานประจำวัน (Top Planning & Timeline Sections)
*แยกเป็น 2 กล่องอิสระออกจากกัน ไม่ต้องสลับแท็บ สามารถเปิดดูควบคู่กันได้ทันที และมีปุ่ม ย่อ/ขยาย แต่ละกล่องได้ตามต้องการ*

1. 📅 **ปฏิทินไทม์ไลน์ (Timeline Calendar):**
   * แสดงแถบงานทอดยาวตั้งแต่วันที่เริ่มงาน (`task.date`) จนถึงวันครบกำหนดส่ง (`task.deadline`) โดยอัตโนมัติ
   * สัญลักษณ์: 🚩 วันเริ่ม, ↔️ กำลังดำเนินงาน, 🏁 วันครบกำหนดส่ง, 📌 งานวันเดียว
   * **🏷️ แถบปุ่มกดดูประเภทงานในปฏิทิน (Multi-Select Task Type Filters):**
     * **ค่าเริ่มต้นของปฏิทินที่แยกอย่างเหมาะสม:** 
       * **ปฏิทินภาพรวมทีม:** ค่าเริ่มต้นเลือกแสดงงาน **`🎬 Roll A` + `🚀 ปล่อยงาน`** เพื่อให้เห็นไทม์ไลน์ภาพรวมตั้งแต่เริ่มถ่ายทำจนถึงวันปล่อยคลิป
       * **ปฏิทินไทม์ไลน์ของแต่ละคน:** ค่าเริ่มต้นจะ **แสดงงานทั้งหมด (ทุกประเภทงาน)** เป็นค่าแรก เพื่อให้ทีมงานแต่ละคนเห็นภาระงานของตนเองครบถ้วนในทุกขั้นตอน
     * **เลือกได้มากกว่า 1 ประเภทพร้อมกัน:** สามารถคลิกเลือกผสมผสานประเภทงานที่ต้องการดูพร้อมกันได้หลายประเภท เช่น ติ๊กทั้ง `🎬 Roll A` และ `✂️ ตัดต่อ` เพื่อดูเฉพาะงาน 2 ประเภทนี้บนปฏิทินพร้อมกัน
     * แต่ละปุ่มแสดงตัวเลขนับจำนวนงานของประเภทนั้นๆ และมีเครื่องหมายถูก `✓` พร้อมกรอบไฮไลต์ชัดเจนเมื่อถูกเลือก
     * มีปุ่ม `🔄 แสดงทุกประเภทงาน` และปุ่ม `✕` เพื่อล้างตัวกรองกลับมาดูงานทั้งหมดได้ในคลิกเดียว
     * มีป้ายสรุปสถานะแสดงจำนวนประเภทที่กำลังเลือกดู และจำนวนงานที่ตรงเงื่อนไข
     * บนแถบปฏิทินไทม์ไลน์จะแสดงไอคอนประเภทงานกำกับไว้ด้วย ช่วยให้มองเห็นประเภทงานได้อย่างรวดเร็ว
   * **🎨 สีกำกับงานแบบสีทึบชัดเจน 15 สี (15 Distinct Solid Calendar Colors):** ปรับการแสดงผลแถบงานในปฏิทินเป็น **สีทึบสดใส (Solid Color Bars)** สไตล์ Google Calendar คอนทราสต์ชัดเจน มองเห็นและแยกแยะประเภทงานได้ทันทีจากระยะไกล ตัวหนังสือสีขาวคมชัด (และตัวหนังสือสีเข้มบนเฉดสีสว่าง) รองรับทั้ง 15 เฉดสี (ฟ้าคราม, เขียวมรกต, ม่วงไวโอเล็ต, ส้มอำพัน, ชมพูกุหลาบ, เขียวทะเล, น้ำเงินคราม, เหลืองทอง, แดงทับทิม, เทาชาร์โคล, เขียวมะนาว, ฟ้าไซแอน, ชมพูบานเย็น, ส้มเพลิง, น้ำตาลคาราเมล) สวยงามทั้งโหมดสว่างและโหมดมืด
   * **📏 แถวไทม์ไลน์ระนาบเดียวกัน (Aligned Multi-day Task Tracks):** งานที่ทอดยาวหลายวันจะแสดงผลอยู่ในแถว (Slot / Track) เดียวกันตลอดทั้งช่วงเวลาอย่างต่อเนื่อง ไม่กระโดดขึ้นลงระหว่างวัน ช่วยให้เห็นไทม์ไลน์ที่ทอดยาวได้อย่างชัดเจน
   * **📝 ตัวหนังสือบรรทัดเดียว เรียบง่าย สบายตา (Single-line Compact Display):** ชื่องานแสดงผลในบรรทัดเดียวอย่างกะทัดรัด ไม่แสดงรูปโปรไฟล์ของแต่ละคนบนแถบปฏิทินเพื่อลดความแออัด โดยแสดงเฉพาะ **ไอคอนลักษณะงาน (เช่น 🎬, ✂️, 🛠️) ต่อท้ายชื่องาน** พร้อมสถานะ ✓ หรือ ⚠️ อย่างเป็นระเบียบชัดเจน
   * **📋 คลิกดูรายละเอียดข้อมูลงานก่อนแก้ไข (Task Details View):** เมื่อคลิกที่แถบงานในปฏิทิน ระบบจะเปิดหน้าต่าง **"รายละเอียดข้อมูลงาน"** ขึ้นมาให้ตรวจสอบข้อมูลก่อนอย่างครบถ้วน (ชื่องาน, สถานะ, ความสำคัญ, กำหนดการ, ผู้รับผิดชอบ, หมายเหตุ และลิงก์ส่งงานที่คลิกได้ทันที) พร้อมปุ่มลัดปรับสถานะงาน และมีปุ่ม **"✏️ แก้ไขงานนี้"** เพื่อเข้าสู่หน้าต่างแก้ไขข้อมูลงานได้อย่างสะดวก

2. ☀️ **สรุปงานประจำวัน (Daily Summary & Agenda):**
   * มีปุ่มเลือกวัน: `◀ ก่อนหน้า`, `วันนี้`, `ถัดไป ▶` พร้อม Date Picker
   * แสดง Badge ประเภทงาน (Roll A, ins, ตัดต่อ, Short, เขียนสคริปต์, กราฟฟิก, ปล่อยงาน, แก้งาน) ในการ์ดของแต่ละคนทันที
   * จัดหมวดหมู่ชัดเจน: 🚨 ต้องส่งวันนี้, ⚡ กำลังทำ, ⚠️ งานค้างเกินกำหนด, ✅ เสร็จแล้ว
   * **เรียงลำดับตามความสำคัญ (Priority Sorting):** งานในทุกหมวดจะเรียงลำดับจาก **ด่วน (🔥) ➔ ปกติ ➔ ไม่รีบ** พร้อมแสดงป้ายความสำคัญอย่างชัดเจน ช่วยให้รู้ว่าควรโฟกัสงานใดก่อน
   * **🔄 ปรับสถานะงานได้ครบวงจร (Multi-Status Control):** ปรับเปลี่ยนจากการมีเพียงปุ่มติ๊กถูกอย่างเดียว ให้สามารถเลือกและปรับสถานะงานได้ครบทุกขั้น:
     * **ชุดปุ่มเลือกสถานะ 3 ระดับ:** มีปุ่มกด `[ รอ ]`, `[ กำลังทำ ⚡ ]`, `[ เสร็จ ✓ ]` ให้คลิกเปลี่ยนสถานะของงานได้ในคลิกเดียว โดยแสดงสีไฮไลต์ตามสถานะปัจจุบันอย่างชัดเจน
     * **ปุ่มไอคอนสลับสถานะต่อเนื่อง:** คลิกที่ไอคอนด้านหน้าการ์ด (`📋` / `⚡` / `✓`) เพื่อวนสถานะถัดไปได้อย่างรวดเร็ว
     * งานจะสลับย้ายกลุ่มระหว่างหมวด "ต้องส่งวันนี้/กำลังทำ/งานค้าง" กับ "ทำเสร็จแล้ว" ทันที พร้อมอัปเดตหลอดความคืบหน้ารายวันอัตโนมัติ
   * หลอด Progress Bar ความคืบหน้าของงานในแต่ละวัน

### 2. ส่วนถัดมา: ภาระงานและกระดานจัดการงาน (Workload, Filters & Kanban/Table)
* **ภาระงานรายบุคคล (Team Workload):** แสดงสัดส่วนงานของลูกทีมแต่ละคน (To Do, In Progress, Done, Overdue)
* **ระบบค้นหาและคัดกรองงาน (Search & Filters Bar):**
  * ค้นหาตามชื่องาน / ประเภทตัวเลือก / หมายเหตุ
  * กรองตามผู้รับผิดชอบ (ทุกคน หรือเลือกลูกทีมเฉพาะคน)
  * กรองตามสถานะ (To Do, In Progress, Done)
* **กระดานงานและตารางงาน (Task Board & Table View):**
  * **ค่าเริ่มต้นเป็นตารางงาน (Table View):** รายการงานทั้งหมดในทีมจะเปิดด้วยมุมมอง `📋 ตารางงาน` เป็นค่าเริ่มต้นทันทีเมื่อเปิดระบบ
  * **เรียงลำดับตามกำหนดส่ง (Deadline Sorted):** งานในตารางถูกจัดเรียงตามกำหนดส่ง (Deadline) จากงานที่ใกล้ถึงกำหนดส่งขึ้นก่อน ช่วยให้ทีมเห็นความเร่งด่วนของแต่ละโปรเจกต์ได้อย่างชัดเจน
  * **สลับมุมมองได้อิสระ:** สามารถกดสลับระหว่าง `📋 ตารางงาน` และ `📊 Kanban รวม` (ลากวางการ์ดได้) ได้ตลอดเวลา พร้อม Badge สัญลักษณ์ครบถ้วน

## 🏆 สรุปยอดผลงานประจำเดือน (Monthly Content Output & KPI Counter)

ระบบมีกล่อง **สรุปยอดผลงานประจำเดือน (Monthly Content Output Counter)** อยู่ด้านบน เพื่อติดตามผลงานที่ทำสำเร็จแล้วในแต่ละเดือน:
* **🎬 Long Form (Long Form Videos Deliverables):** นับจำนวนวิดีโอตัวยาวที่ตัดต่อเสร็จ ตรวจ Final และปล่อยงานเผยแพร่จริงสำเร็จในเดือนนี้ (คำนวณจากประเภท "ปล่อยงาน")
* **📱 คลิปสั้น / Short (Completed Shorts & Reels):** นับจำนวนคลิปสั้นแนวตั้ง (TikTok, Reels, Shorts) ที่ทำเสร็จสิ้นในเดือนนี้
* **✂️ ตัดต่อสำเร็จ (Video Edits Completed):** นับจำนวนงานตัดต่อคลิปที่เสร็จสิ้นสมบูรณ์ในเดือนนี้
* **📝 เขียนสคริปต์ (Scriptwriting Completed):** นับจำนวนบทสคริปต์วิดีโอหรือเนื้อหาที่เขียนเสร็จสมบูรณ์ในเดือนนี้ (คำนวณจากประเภท "เขียนสคริปต์")
* **🎨 กราฟฟิก & ภาพปก (Graphics / Covers Completed):** นับจำนวนหน้าปก Thumbnail หรือ Motion Graphics ที่ออกแบบเสร็จสิ้น
* **🏆 ผลงานสำเร็จรวมทั้งหมดประจำเดือน (Total Monthly Deliverables & Progress %):** คำนวณอัตราความสำเร็จจากแผนงานทั้งหมดประจำเดือน พร้อมแถบ Progress Bar แสดงเปอร์เซ็นต์ความคืบหน้ารวม
* **ปรับตามมุมมองผู้ใช้:** 
  * ในมุมมอง **"เห็นภาพรวมทุกคน"**: แสดงยอดส่งมอบผลงานรวมของทั้งทีม
  * ในมุมมอง **ทีมงานแต่ละคน**: แสดงเฉพาะยอดผลงานที่ทีมงานคนนั้นเป็นผู้รับผิดชอบและทำเสร็จสิ้น

## 💾 การจัดเก็บข้อมูลและระบบ Cloudflare Sync
* **การทำงานแบบไฮบริด (Hybrid Offline-First):** ระบบบันทึกข้อมูลแบบ Optimistic Update ลงใน **LocalStorage** (`team_taskflow_v9`) ทันทีที่ทำงาน ทำให้ระบบเร็ว ลื่นไหล ใช้งานได้แม้ไม่มีอินเทอร์เน็ต
* **Cloudflare D1 Real-Time Sync:** เมื่อเปิดผ่านโดเมนบน Cloudflare Pages ระบบจะซิงค์ข้อมูลกับฐานข้อมูล **Cloudflare D1 Serverless Database** แบบอัตโนมัติสองทาง (Two-Way Sync) พร้อมป้ายแสดงสถานะ `☁️ Cloud D1` บนแถบเมนูด้านบน
* มีปุ่ม **Export JSON** สำรองข้อมูล และ **Import JSON** กู้คืนข้อมูล
* มีปุ่ม **Reset ข้อมูลตัวอย่าง** เพื่อเริ่มต้นทดลองระบบใหม่ได้ทุกเมื่อ

## ☁️ คู่มือการนำขึ้น Cloudflare Pages และเชื่อมต่อ Cloudflare D1 Database

โปรเจกต์นี้ได้รับการพัฒนาให้รองรับ **Cloudflare Pages + Cloudflare Pages Functions + Cloudflare D1 Serverless SQLite Database** อย่างสมบูรณ์แบบ ใช้งานฟรี 100% ไม่มีค่าบริการเซิร์ฟเวอร์ และมีความเร็วระดับ Edge Global CDN

### 📁 โครงสร้างไฟล์สำหรับ Cloudflare:
* `index.html` — หน้าเว็บหลักพร้อมระบบ Cloudflare D1 Auto-Sync & Local Fallback
* `functions/api/tasks.js` — API Endpoint สำหรับดึงรายการงาน (GET), บันทึก/อัปเดตงาน (POST) และลบงาน (DELETE)
* `functions/api/sync.js` — API Endpoint สำหรับ Batch Sync ข้อมูลทั้งหมดขึ้น D1 ในคำสั่งเดียว
* `functions/api/init.js` — API Endpoint สำหรับตรวจสอบสถานะและสร้าง Table อัตโนมัติ (Zero-Config)
* `schema.sql` — โครงสร้างฐานข้อมูล SQLite สำหรับ Cloudflare D1 พร้อม Indexes
* `wrangler.toml` — ไฟล์คอนฟิกสำหรับ Cloudflare Pages และ D1 Binding
* `_headers` — ไฟล์คอนฟิกความปลอดภัยและ CORS Headers

### 🚀 วิธีติดตั้งและขึ้นระบบ (Deployment Guide)

สามารถทำได้ 2 วิธีง่ายๆ:

#### วิธีที่ 1: Deploy ผ่าน Cloudflare Dashboard (ผ่าน GitHub/GitLab - ง่ายที่สุด ⭐ แนะนำ)

1. **นำโฟลเดอร์นี้ขึ้น Git Repository ของคุณ:**
   - โฟลเดอร์นี้ได้รับการตั้งค่า `git init` และสร้าง Commit พร้อมใช้งานไว้แล้ว
   - สามารถสร้าง New Repository บน [GitHub](https://github.com/new) แล้วรันคำสั่ง:
     ```bash
     git remote add origin <URL_REPOSITORY_ของคุณ>
     git branch -M main
     git push -u origin main
     ```

2. **สร้าง Pages Project บน Cloudflare:**
   - เข้าสู่แดชบอร์ด [Cloudflare Dashboard](https://dash.cloudflare.com/)
   - เมนูด้านซ้ายเลือก **Workers & Pages** ➔ คลิกปุ่ม **Create application**
   - เลือกแท็บ **Pages** ➔ คลิก **Connect to Git**
   - เลือก Repository ที่คุณเพิ่งอัปโหลดไป
   - ตั้งค่า Build settings:
     - **Project name:** `team-taskflow`
     - **Framework preset:** `None`
     - **Build command:** *เว้นว่างไว้*
     - **Build output directory:** `.` (เครื่องหมายจุด หรือเว้นว่าง)
   - คลิก **Save and Deploy** (หน้าเว็บจะพร้อมใช้งานที่ `team-taskflow.pages.dev` ภายในไม่กี่วินาที)

3. **สร้าง Cloudflare D1 Database:**
   - ใน Cloudflare Dashboard เมนูด้านซ้ายคลิก **Storage & Databases** ➔ **D1 SQL Database**
   - คลิกปุ่ม **Create database**
   - ตั้งชื่อ Database เช่น `team-taskflow-db`
   - คลิก **Create**

4. **ผูก D1 Database เข้ากับ Cloudflare Pages (Binding):**
   - กลับไปที่เมนู **Workers & Pages** ➔ คลิกเข้าไปที่โปรเจกต์ `team-taskflow` ของเรา
   - ไปที่แท็บ **Settings** ➔ เมนูด้านซ้ายเลือก **Functions**
   - เลื่อนลงมาที่หัวข้อ **D1 Database Bindings** ➔ คลิก **Add binding**
   - กรอกข้อมูลดังนี้:
     - **Variable name:** `DB` *(ต้องเป็นตัวพิมพ์ใหญ่ DB เท่านั้น)*
     - **D1 database:** เลือก `team-taskflow-db` ที่สร้างไว้
   - คลิก **Save**
   - ไปที่แท็บ **Deployments** ➔ คลิกเมนู 3 จุดที่การ Deploy ล่าสุด แล้วเลือก **Retry deployment** (เพื่อให้ระบบโหลดการเชื่อมต่อฐานข้อมูลใหม่)

5. **ระบบสร้างตารางและซิงค์ข้อมูลให้อัตโนมัติ (Zero-Config Database Init):**
   - เมื่อเปิดเข้าเว็บ `https://team-taskflow.pages.dev` ตัว API มีระบบ Auto Ensure Table ตรวจสอบและสร้างตาราง `tasks` พร้อม Indexes ให้อัตโนมัติทันที
   - หากฐานข้อมูลยังว่างเปล่า ระบบหน้าเว็บจะอัปโหลดข้อมูลงานเริ่มต้น (Initial Tasks) ขึ้นไปเก็บไว้ใน Cloudflare D1 ให้อัตโนมัติ
   - แถบเมนูด้านบนจะแสดงสถานะ `☁️ Cloud D1` สีเขียว พร้อมใช้งานทันทีสำหรับทุกคนในทีม!

#### วิธีที่ 2: Deploy ผ่าน Wrangler CLI (สำหรับผู้ที่มี Node.js / Wrangler)

หากคุณติดตั้ง Node.js และ Wrangler CLI ไว้ในเครื่อง สามารถสั่งงานผ่าน Terminal ได้โดยตรง:

1. **สร้าง Cloudflare D1 Database:**
   ```bash
   npx wrangler d1 create team-taskflow-db
   ```
   ระบบจะแสดงผล `database_id` ออกมา ให้นำค่านั้นไปใส่แทนที่ `database_id` ในไฟล์ [wrangler.toml](file:///Users/techmx/Documents/team-todo-list/wrangler.toml)

2. **สั่งสร้างตารางในฐานข้อมูล Cloudflare D1:**
   ```bash
   npx wrangler d1 execute team-taskflow-db --file=./schema.sql --remote
   ```

3. **Deploy ขึ้น Cloudflare Pages:**
   ```bash
   npx wrangler pages deploy . --project-name team-taskflow
   ```

### 🛡️ คุณสมบัติด้านความปลอดภัยและความเสถียร (Reliability & Performance)
* **Zero-Cold-Start Serverless:** Cloudflare Pages Functions ทำงานบนโครงข่าย V8 Isolates ของ Cloudflare ทั่วโลก รวดเร็วระดับเสี้ยววินาที
* **Offline Resilience:** หากผู้ใช้งานไม่มีอินเทอร์เน็ต สามารถเพิ่ม ลบ แก้ไขงานได้ตามปกติ ระบบจะบันทึกลงในเครื่อง และเมื่อเชื่อมต่ออินเทอร์เน็ตอีกครั้ง ข้อมูลจะพร้อมซิงค์ขึ้น Cloud ทันที
* **Edge Backup:** ข้อมูลจัดเก็บอยู่บน Cloudflare D1 พร้อมระบบสำรองและสำรองไฟล์ JSON ที่ดาวน์โหลดเก็บไว้ในเครื่องได้ตลอดเวลา
